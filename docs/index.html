QA Skills

Claude Code plugins that take QA from design to running tests.

Getting started

Run these inside Claude Code. Do step 1 once per machine.

/plugin marketplace add backend-timedoor/qa-skills
/plugin install qa-ai-flow@qa-skills

Then, in your project folder:

/setup-qa-ai-flow

To get new versions later: /plugin marketplace update qa-skills

Plugins

qa-ai-flow v0.1.0

Figma designs to test cases, upload to Notion, generate Playwright tests.

pre-launch-check v0.1.0

Before-launch website checklist for dev/staging: crawl, automated checks, Claude review, report, optional Notion sync.

post-launch-check v0.1.0

After-launch website checklist for the live site: indexing, analytics, HTTPS, performance, images, report, optional Notion sync.
